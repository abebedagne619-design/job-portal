# 🎯 Job Portal - Full Stack Application

A full-stack job portal with ML-powered job recommendations.

## 🚀 Features

- ✅ User Authentication (JWT + Google OAuth)
- ✅ Job Listings & Search
- ✅ ML Job Recommendations
- ✅ Real-time Chat
- ✅ Interview Scheduling
- ✅ Analytics Dashboard

## 🛠️ Tech Stack

- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Database**: MySQL
- **ML**: Python + Scikit-learn
- **Real-time**: Socket.IO

## 🚀 Installation

1. Clone the repo
2. Setup backend: `cd server && npm install && npm run dev`
3. Setup frontend: `cd client && npm install && npm run dev`
4. Setup ML: `cd ml-service && python recommendation_service.py`
